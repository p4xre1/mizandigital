# ميزان الرقمية

نسخة عربية ثابتة وسريعة من منصة ميزان الرقمية، موجهة لطلبة القانون والعلوم القانونية بالمغرب.

## الصفحات

- `/` الصفحة الرئيسية والبحث في الملخصات.
- `/s4` مركز السداسي الرابع.
- `/lexicon` القاموس القانوني العربي/الفرنسي.

## المبدأ التقني

الموقع يعمل ببيانات محلية من `src/data/` ولا يعتمد على تسجيل الدخول أو Supabase أو واجهات API أو وحدات إعلانية. ملفات PDF توضع داخل `public/docs/` وتُربط من خلال `src/data/docs.json`.

## التشغيل

```bash
pnpm install
pnpm dev
pnpm build
```

الاستضافة المناسبة هي Cloudflare Pages أو أي استضافة ملفات ثابتة تدعم fallback إلى `index.html`.
