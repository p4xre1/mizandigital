# ميزان الرقمية

نسخة عربية ثابتة وسريعة من منصة ميزان الرقمية، موجهة لطلبة القانون والعلوم القانونية بالمغرب.

---

## 🚀 المميزات الرئيسية

* **تغطية شاملة السداسيات**: مسارات مخصصة لجميع السداسيات من **S1 إلى S6**.
* **مكتبة وأرشيف ملخصات**: وصول سريع للملفات والنماذج مع إمكانية الفلترة والبحث.
* **إشعار نجاح التحميل**: تنبيه لحظي (Toast) يؤكد نجاح تحميل أي ملف PDF من الأرشيف.
* **قاموس قانوني ثنائي اللغة**: مصطلحات قانونية (عربي/فرنسي) مع التعريفات والصفحات المخصصة.
* **دليل كليات الحقوق بالمغرب**: بطاقات تعريفية للمؤسسات الجامعية مع روابطها الرسمية.
* **أخبار وندوات**: متابعة للأنشطة القانونية واللقاءات الأكاديمية.
* **أداء فائق وبدون إعلانات**: تجربة قراءة سلسة تدعم الوضعين الداكن والفاتح.

---

## 📌 مسارات الصفحات (Routing)

* `/` — الصفحة الرئيسية والبحث الشامل.
* `/archive` — الأرشيف والمكتبة الرقمية.
* `/s1` حتى `/s6` — توجيه مباشر ومُخصص للسداسي المحدد (S1, S2, S3, S4, S5, S6).
* `/news` & `/articles` — الأخبار والمقالات المنهجية.
* `/lexicon` — القاموس القانوني العربي/الفرنسي.
* `/events` — أرشيف الندوات واللقاءات الأكاديمية.
* `/schools` — دليل كليات الحقوق بالمغرب.

---

## 🛠️ المبدأ التقني

الموقع يعمل ببيانات محلية ثابته من مجلد `src/data/` ولا يعتمد على تسجيل الدخول أو قواعد بيانات خارجية أو واجهات API أو وحدات إعلانية.
توضع ملفات الـ PDF المتاحة للتحميل داخل المجلد `public/docs/` وتُربط مع التطبيق عبر ملف `src/data/docs.json`.

عند الضغط على زر "تحميل PDF"، يُطلق التطبيق حدثاً مخصصاً (`mizan:toast`) عبر `window`، يلتقطه `App.tsx` ليعرض مكوّن `Toast` أسفل الشاشة لمدة 3 ثوانٍ كتأكيد بصري لنجاح التحميل.
