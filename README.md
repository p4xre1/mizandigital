# ميزان الرقمية

منصة رقمية مغربية متطورة وموجهة لطلبة القانون والعلوم القانونية، لتسهيل الولوج إلى الملخصات، النصوص التشريعية، والمعجم القانوني مزدوج اللغة.

---

## 🚀 المميزات الرئيسية

* **تغطية شاملة للسداسيات**: مسارات مخصصة لجميع السداسيات من **S1 إلى S6**.
* **مكتبة وأرشيف ملخصات**: وصول سريع للملفات والنماذج مع إمكانية الفلترة والبحث المتقدم.
* **إشعار نجاح التحميل**: تنبيه لحظي (Toast) يؤكد نجاح تحميل أي ملف PDF من الأرشيف.
* **قاموس قانوني ثنائي اللغة**: مصطلحات قانونية (عربي/فرنسي) متصلة بقاعدة بيانات ديناميكية مع التعريفات والصفحات المخصصة.
* **دليل كليات الحقوق بالمغرب**: بطاقات تعريفية للمؤسسات الجامعية مع روابطها الرسمية.
* **أخبار وندوات**: متابعة للأنشطة القانونية واللقاءات الأكاديمية.
* **أداء فائق**: تجربة تصفح سريعة وسلسة تدعم الوضعين الداكن والفاتح.

---

## 📌 مسارات الصفحات (Routing)

* `/` — الصفحة الرئيسية والبحث الشامل.
* `/archive` — الأرشيف والمكتبة الرقمية.
* `/s1` حتى `/s6` — توجيه مباشر ومُخصص للسداسي المحدد (S1, S2, S3, S4, S5, S6).
* `/news` & `/articles` — الأخبار والمقالات المنهجية.
* `/lexicon` — القاموس القانوني العربي/الفرنسي (قاعدة البيانات الديناميكية).
* `/lexicon/:slug` — الصفحة التفصيلية لكل مصطلح قانوني.
* `/events` — أرشيف الندوات واللقاءات الأكاديمية.
* `/schools` — دليل كليات الحقوق بالمغرب.

---

## 🛠️ المبدأ التقني

يعتمد الموقع على بنية تقنية حديثة وعالية الأداء باستخدام **React**، **TypeScript**، و**Tailwind CSS**، مع ربط جزء من البيانات الديناميكية (مثل المعجم القانوني `lexicon_terms`) بقاعدة بيانات **Supabase** لضمان المرونة وسهولة التحديث المستمر. 
بالإضافة إلى ذلك، يتم الاعتماد على ملفات JSON محلية داخل `src/data/` للبيانات الثابتة، وملفات الـ PDF داخل المجلد `public/docs/`.

عند الضغط على زر "تحميل PDF"، يُطلق التطبيق حدثاً مخصصاً (`mizan:toast`) عبر `window`، يلتقطه `App.tsx` ليعرض مكوّن `Toast` أسفل الشاشة لمدة 3 ثوانٍ كتأكيد بصري لنجاح التحميل.
