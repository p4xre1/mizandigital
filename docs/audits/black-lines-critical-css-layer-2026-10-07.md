| قبل | بعد |
|---|---|
| كل حدود بلا صنف لون صريح تُرسم بلون النص `rgb(15,23,41)` | `rgb(226,232,240)` (فاتح) / `rgb(51,65,85)` (داكن) كما في التصميم |

## 2. السبب الجذري

ملف الأنماط المبنى ينظّم Tailwind عبر طبقات:

```css
@layer base { *,:after,:before { box-sizing:border-box; border:0 solid; margin:0; padding:0 } }
@layer base { * { border-color: hsl(var(--border)) } }   /* من globals.css */
@layer utilities { … }
```

و`scripts/lib/critical-css.mjs` (كتلة CSS الحرجة المضمَّنة في `<head>` لحماية CLS) كان **ينزع غلاف `@layer`** عن كل قاعدة يستخرجها — والنتيجة في رأس المستند:

```html
<style data-mizan-critical-css>
  …
  *,:after,:before{box-sizing:border-box;border:0 solid;margin:0;padding:0}  <!-- بلا طبقة! -->
</style>
```

وقاعدة السلسلة الحاسمة: **النمط غير المُطبَّق على طبقة يغلب كل الأنماط المُطبَّقة عليها، مهما كانت خصوصيتها.** فالقاعدة العارية أعلاه (`border:0 solid` ⇒ `border-color:currentColor`) تغلب `*{border-color:hsl(var(--border))}` في `@layer base`، فيرجع `border-color` إلى لون النص — أي حدود داكنة/سوداء.

في الوضع الداكن كان النص أبيض، فبدت الحدود «فضية فاتحة» مقبولة بصرياً؛ ولهذا ظهر العطل فقط في الوضع الفاتح (وهو الوضع الافتراضي لمعظم الزوار).

**الحدود المتأثرة:** كل عنصر حدود بلا صنف لون صريح — البطاقات والأزرار والرأس وحقول البحث والفقرات المفصولة، أي مئات العناصر في كل صفحة.

## 3. الإصلاح

`scripts/lib/critical-css.mjs`:

1. **تُنسخ كل قاعدة داخل `@layer` الأصلي نفسه** بدل نزعه.
2. **تُصدَّر تعليمة ترتيب الطبقات كاملة** أول الكتلة:
   `@layer properties, theme, base, components, utilities;` — فالطبقة تُرتَّب من أول ذكر لها في المستند، وبدون هذا السطر قد تُرتَّب طبقات الكتلة قبل `properties/theme` فتنقلب الأولوية بين `components` و`utilities` عند دمجها مع النمط الكامل.
3. **دمج متتالٍ بسياقين:** غلاف طبقة واحد لكل مجموعة قواعد متتابعة، وكتلة `@supports/@media` واحدة لكل مجموعة تشترك السياق نفسه (كان الغلاف يتكرر عند كل قاعدة `@supports`، وهذا وحده كان يضخّم الكتلة بسعر لا لزوم له).
4. نتيجة جانبية مقصودة: صار شكل الكتلة أقرب إلى ملف الأنماط نفسه، وارتفع عدد الصفحات الحاملة لها من 182 إلى **183** (حارس نسبة النص/HTML صار يمرّ لأربع صفحات كان إخفاقها وشيكاً: FCP أفضل، لا أسوأ).

الحجم: الرئيسية 7,632 ⇒ **7,736 بايت** (حد البناء 8,192)، وباقي الصفحات 4,812 بايت. كلها داخل السقف ونسبة النص/HTML للرئيسية 0.138.

**الحارسان الجديدان** (`tests/critical-css.test.ts`): لا قاعدة عارية على المستوى الأعلى في الكتلة (وحدة مستقلة عن البناء)، وكل قواعد `dist/index.html` داخل `@layer` مع تعليمة ترتيب الطبقات في المقدمة.

## 5. القاعدة المستخلصة

CSS بلا طبقة يغلب كل CSS مُطبَّق على طبقة — فأي «اقتطاع» أو «تحسين» يعيد كتابة قواعد Tailwind خارج `@layer` يعيد إنتاج هذا العطل نفسه. الكتلة الحرجة يجب أن تكون **انعكاساً أميناً للملف**: الطبقة والترتيب والسياق، لا القواعد وحدها.
