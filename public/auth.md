# Mizan Digital Agent Authentication

Mizan Digital public discovery resources are readable without authentication.

## Public access

The following resources are public:

- Website: https://www.mizan.page/
- Markdown representation: https://www.mizan.page/index.md
- Sitemap: https://www.mizan.page/sitemap.xml
- Agent card: https://www.mizan.page/.well-known/agent-card.json
- AI catalog: https://www.mizan.page/.well-known/ai-catalog.json
- Agent skills index: https://www.mizan.page/.well-known/agent-skills/index.json

## Authentication

No OAuth/OIDC authorization server is advertised for the public content resources. Agents should not send credentials to public read-only pages.

## Legal verification

For Moroccan legal claims, agents should prefer official government sources linked from Mizan pages and distinguish educational summaries from official legislation.
